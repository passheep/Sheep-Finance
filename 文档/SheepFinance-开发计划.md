## 1. 执行原则

- 先验证 Excel/WPS、A4 画布和阿里云签名三个高风险点，再铺开完整界面。
- 每个阶段都形成可运行、可验证的增量，不把导出和安装包留到最后才首次尝试。
- 保持固定模板、最多 5 笔、A4 单页等首版边界，不提前扩展模板设计器和多页逻辑。
- 原图、当前编辑值和识别原始依据分离保存，任何自动处理都不能破坏原始证据。
- 所有异步结果依赖稳定费用项 ID 和请求版本号，排序、删除后不得串行。

## 2. 里程碑总览

| 里程碑 | 目标 | 完成门槛 |
| --- | --- | --- |
| M0 技术验证 | 消除 WPS、A4、OCR 调用风险 | 生成样例 Excel/PDF，完成一次真实 OCR 调用 |
| M1 本地基础 | 项目可安装、数据可持久化 | 新建、保存、重启恢复草稿 |
| M2 制单工作台 | 无 API 时也能完整手工制单 | 1 至 5 条费用可编辑、排序、排版 |
| M3 智能识别 | OCR 与 AI 自动填充可用 | 两种 OCR 模式和结构化 AI 提取闭环 |
| M4 导出与历史 | 完成实际业务闭环 | PDF/Excel 另存为、历史记录可回溯 |
| M5 发布候选 | 可线下分发 | Win10 安装包及完整回归通过 |

## 3. 阶段任务

### 阶段 0：技术验证

#### 0.1 模板与 WPS 验证

- [ ] 固化参考模板的字体、列宽、行高、边框、合并区域和页边距规格。
- [ ] 使用 Rust 生成仅含 1 条费用的 Excel。
- [ ] 生成含 2 条和 5 条费用的 Excel，验证动态行和合计区域。
- [ ] 嵌入 1 张和 5 张处理后图片，设置 A4 纵向及单页缩放。

- [ ] 确认 Excel 不包含参考文件中的其他数据或隐藏对象。

验收：3 份样例 Excel 均能由 WPS 打开，无修复提示，合计正确，图片可见，打印范围受控。

#### 0.2 A4 编辑器验证

- [ ] 建立 A4 毫米坐标系和屏幕缩放换算。
- [ ] 用 Konva 绘制模板表格、文字和图片。
- [ ] 验证点击文字后覆盖 HTML 输入控件的定位。

验收：缩放窗口不改变打印坐标，PDF 与应用预览结构一致，中文文字和票据可读。

#### 0.3 识别链路验证

- [ ] 在 Rust 后端完成阿里云 OCR 鉴权和签名最小调用。

- [ ] 将 OCR 文字块发送给一个 DeepSeek 或 GPT 配置。
- [ ] 使用固定 JSON 结构接收日期、事由、说明和金额。

验收：至少使用一张脱敏样本完成“图片 → OCR → AI JSON → 校验后字段”的闭环，并记录请求耗时和错误信息。

## 4. 重点测试矩阵

### 4.1 图片与列表

- 1、2、3、4、5 张图片的自动布局。
- 第 6 张图片被拒绝，删除后可继续上传。
- PNG、JPEG、剪贴板截图、带 EXIF 旋转照片、超大图片。
- OCR 进行中排序、删除、关闭应用和重新打开。
- 相同图片重复上传提示但不误删原记录。

### 4.2 字段与计算

- AI 识别值、人工修改值和重新识别结果的合并。
- 事由只能从启用字典中选择，停用历史项仍能显示。
- 默认资料唯一性以及历史快照隔离。
- 金额 `0.01`、`10.00`、`1001.05` 等人民币大写转换。
- 自动合计、人工覆盖和恢复自动合计。
- 内容说明过长、换行和特殊字符。

### 4.3 API 与网络

- 两种 OCR 接口调用正确。
- AccessKey 错误、限流、超时、网络中断和无效响应。
- 大模型返回 Markdown、空文本、非法 JSON、未知事由或错误金额。
- OCR 成功但 AI 失败时仍可查看原文并手工填写。
- API 配置切换后，历史识别记录仍显示原配置名称快照。

### 4.4 导出与打印

- 1 至 5 行费用的 Excel 合并区域、公式和样式。
- 1 至 5 张图片裁剪、旋转后嵌入 Excel/PDF。
- A4 单页、越界提示、打印安全边距和不同打印机缩放。
- WPS 个人版打开、保存、另存和打印预览。
- 中文文件名、中文目录、覆盖同名文件和磁盘空间不足。
- 导出文件不包含其他记录、OCR 原始 JSON、密钥或本地绝对路径。

## 5. 每阶段质量门槛

每个可交付阶段至少执行：

```text
npm run build
cargo fmt --check
cargo check
cargo test
```

建立测试脚本后补充前端单元测试和端到端测试。涉及安装与系统集成的里程碑还必须执行真实 `tauri build`，并验证生成的安装程序，而不是只验证开发模式。

## 6. 首版完成定义

只有同时满足以下条件，首版才视为完成：

- 开发设计文档中的 12 条验收标准全部通过；
- 参考模板字段映射已由业务方确认；
- 至少一组 1 至 5 张图片的完整业务样本通过；
- 阿里云两种 OCR 模式均有真实调用记录；
- DeepSeek 或 GPT 至少一种配置完成真实结构化提取；
- WPS 个人版完成 Excel 验证；
- 单页 PDF 打印结果与应用预览一致；
- 历史记录可在重启后恢复；
- Win10 x64 安装包完成干净环境安装测试；
- 不存在阻塞级数据丢失、金额错误、图片错位或密钥泄露问题。

## 7. 后续版本候选项

- OCR 和大模型耗时优化、缓存及并发策略。
- 专用发票/票据 OCR 自动路由。
- 多模板和模板配置工具。
- 多页报销单及自动分页。
- 发票与付款截图分组、重复费用检测。
- 完全离线 OCR。
- 数据库加密、登录和权限控制。
- 云同步、多人协作和审批流程。
