# 报销单助手（SheepFinance）

> 产品版本：0.3.0 · 文档更新：2026-10-10

报销单助手（原 SheepFinance）是面向行政、财务和报销经办人的 Windows 本地报销单据工作台。它整理发票、车票、小票和支付截图，支持识别、人工复核、A4 排版及 Excel/PDF 导出。

## 主要功能

- 通过文件选择、拖入、粘贴或手机局域网上传添加图片。每单最多 **10 笔费用、30 张图片**，每笔费用的主图和附图合计最多 **10 张**；只有主图参与识别。
- 支持阿里云 OCR 全文识别高精版及通用手写体识别，再由 OpenAI 兼容大模型提取字段。大模型失败时保留 OCR 原文，仍可手工制单。
- 金额支持算术表达式和负数，结果以整数分保存；自动合计可由人工总额覆盖，人民币大写随最终总额生成。重新识别不会静默覆盖人工确认的字段。
- A4 表格按内容动态续页，图片每组 6 张。`single` 在仅有一页表格且余量足够时合入第一组图片，`double` 将图片独立分页；两种模式都可能超过两页，不是页数上限。
- 预览审批栏可选“财务”或“秘书处”，并可隐藏“总经理审核”；新建和旧记录默认使用财务且显示总经理审核，选择随单据保存，Excel/PDF/打印同步。
- 预览表头、费用单元格、人工合计、公司/申请人选择及审批选项支持 100 步撤销/重做；工具栏按钮及 `Ctrl+Z` / `Ctrl+Shift+Z` 可用。输入框内保留原生文本撤销；新建、切单、重新载入清空记录，历史仅在当前会话内保留，不恢复图片文件或网络请求。
- 支持图片裁剪取景、旋转、缩放、移动及排序；使用 DOM/CSS 预览，通过 ExcelJS 导出 Excel，通过 html2canvas + jsPDF 导出 PDF，打印使用页面的 A4 打印样式。
- 桌面端以 SQLite 保存草稿、设置、历史单据和请求记录；原图以 SHA-256 去重并按报销单归集。支持历史查询、标签、报销状态和备份恢复。
- 手机上传二维码默认有效 15 分钟，绑定当前单据或指定费用，随目标剩余容量同步；切换单据后旧会话失效。
- 申请人资料、字典和识别配置可导出、导入加密 TXT。其安全限制见下文。
- 记住上次的窗口大小、位置和最大化状态，重新打开时自动恢复。

新建单据的公司名称、报销日期保留空值，不默认填入公司或当天日期。申请人、部门和收款资料复制默认资料对象的快照；之后修改设置不会回写历史单据。

桌面程序、任务栏、安装/卸载程序和软件内品牌共用由 `文档/报销申请.png` 生成的图标，源图片保留。

## 运行环境

- 目标平台为 Windows 10 x64 及以上，需要满足 Tauri/WebView2 运行条件；干净 Windows 10 实机验收仍待完成。
- WPS Office 可用于打开、编辑导出的 `.xlsx`，软件不依赖 WPS 自动化接口；WPS 打印兼容性尚未完成实机验收。
- 本地编辑、保存和导出无需识别网络；OCR、大模型请求访问配置的互联网服务，手机上传仅在局域网内通信。
- 手机和电脑需位于同一局域网，并允许应用通过防火墙。
- 浏览器运行仅为演示回退：使用 `localStorage`，历史只持久化当前列表前 20 项，没有桌面 SQLite、原图池和恢复能力，不能视为桌面持久化验收。

## 数据与恢复

默认数据目录为 `%APPDATA%\com.sheepfinance.app`，**以桌面运行时返回的实际目录为准**：

```text
com.sheepfinance.app/
├─ sheepfinance.db
├─ images/<报销单ID>/
├─ backups/database/
├─ backups/full/
└─ legacy-json-<时间>/
```

SQLite 当前为 v3、11 张表，启用 WAL、外键和 `synchronous=FULL`。单据 JSON、费用及附件 SQL 在同一事务内保存；图片文件先行写入，不属于 SQL 回滚范围。

数据库快照保留最近 5 份，按最近有效快照的 72 小时间隔及启动/保存路径的条件调度，不是持续运行的定时器。快照只包含数据库，依赖本机图片池。跨电脑迁移需要完整 ZIP，其中包含一致性数据库快照、全部引用图片和哈希清单。

旧 JSON/`.bak` 迁移、归档和损坏恢复门禁继续保留：不能因数据库损坏而静默建立空工作区；至少有一份有效数据库备份后才允许清理旧归档。完整恢复规则见[开发设计文档](文档/SheepFinance-开发设计文档.md)。

## 安全限制

OCR/大模型凭据目前会存在于配置 JSON、SQLite、数据库快照及完整 ZIP 中；浏览器配置同样可能包含凭据。当前**没有 DPAPI 保护**，这些文件都应按敏感资料保管。

配置 TXT 使用 version 1 的 AES-256-GCM、PBKDF2-SHA256（180000 次），密钥来源是程序内置固定 secret，**不是用户密码加密，也不是 Windows 凭据保护**，不能作为强访问控制。不要将真实密钥、报销数据或备份提交到仓库。
